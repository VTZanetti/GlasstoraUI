# Política de segurança

## Versões suportadas

| Versão | Suporte |
| ------ | ------- |
| 0.1.x  | Sim     |

## Reportando uma vulnerabilidade

Use a aba Security do repositório e a opção de aviso privado, ou entre em contato pelo perfil
[@VTZanetti](https://github.com/VTZanetti). Evite abrir uma issue pública com os detalhes.

A resposta inicial costuma sair em até sete dias. Correções são publicadas como versão de patch,
com crédito ao autor do relato quando houver interesse.
